# Data room de GatoPago

Índice de lo que se enseña a inversores y evaluadores en una due diligence. La lista sale del [plan de empresa, finanzas y capital](../../estrategia/planes/gatopago-plan-empresa-finanzas-capital-2026-2030.md), apartado 6.5.

## Reglas de seguridad

- Este repositorio guarda **el índice y los documentos públicos**, nunca los documentos sensibles.
- No versionar contraseñas, claves, credenciales, estados de cuenta, contratos firmados ni datos personales. Esos documentos viven en una carpeta privada con acceso controlado y aquí solo se indica dónde están.
- Las cartas de intención se etiquetan como tales: una carta de intención no es un contrato ni un ingreso.

## Antes de abrir el data room

1. Completar lo que está en **Falta** y es público.
2. Preparar la carpeta privada con acceso por persona y registro de quién entra.
3. Revisar que cada cifra tenga fuente y fecha.
4. Confirmar con el equipo técnico qué significa hoy «autocustodia»: qué puede hacer una persona con sus fondos si GatoPago no está disponible.
