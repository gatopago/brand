# Subvenciones y Grants — GatoPago

Carpeta destinada a solicitudes, seguimiento y entregables de programas de aceleración y subvenciones de ecosistemas (Arbitrum Foundation, Uniswap, Base, etc.).

## Estructura por convocatoria

Para cada convocatoria, crear una carpeta temática con:
- `README.md` (resumen, fechas límite, requisitos y montos).
- Documento de postulación y respuestas oficiales.
- Entregables y reportes de hito comprometidos.
